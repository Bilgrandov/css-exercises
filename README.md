# CSS Foundations Exercises

Kumpulan latihan untuk memperdalam fundamental CSS berdasarkan kurikulum [The Odin Project](https://www.theodinproject.com/).

## Progress Latihan
- [x] `intro-to-css` - Syntax dasar dan cara menghubungkan CSS.
- [ ] `cascade` - Memahami Specificity dan Inheritance.
- [ ] `block-and-inline` - Eksplorasi Box Model.
- [ ] `flex` - Teknik layouting responsif.

## Cara Menjalankan
1. Clone repo ini: `git clone https://github.com/Bilgrandov/css-exercises.git`
2. Buka folder latihan yang diinginkan.
3. Klik kanan pada file `index.html` > **Open with Live Server**.

## Tech Stack
- HTML5
- CSS3 (Vanilla)
