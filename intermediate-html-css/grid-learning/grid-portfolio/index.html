🌐 Portfolio Website

Membangun portfolio website ala Neocities dari scratch dengan Grid + Flexbox

📖 Apa yang Akan Kita Bangun?

Sebuah portfolio website personal yang bisa di-deploy ke Neocities, GitHub Pages, atau hosting manapun. Hanya HTML + CSS murni — tanpa framework!

🗺️ Blueprint Portfolio

┌──────────────────────────────────────────────┐
│  NAVBAR     [Logo]  [Home] [About] [Contact] │
├──────────────────────────────────────────────┤
│  HERO — Nama besar + tagline + tombol CTA    │
├──────────────────────────────────────────────┤
│  ABOUT — Foto + bio (2 kolom)                │
├──────────────────────────────────────────────┤
│  SKILLS — Grid kartu skill (auto-fit)        │
├──────────────────────────────────────────────┤
│  PROJECTS — Grid portfolio cards             │
├──────────────────────────────────────────────┤
│  CONTACT — Form sederhana (2 kolom)          │
├──────────────────────────────────────────────┤
│  FOOTER — links + copyright                  │
└──────────────────────────────────────────────┘

Teknik yang Digunakan

  • Grid — layout section (about 2 kolom, skills cards, projects gallery, footer)
  • Flexbox — navbar, hero content, card internals, tombol groups
  • auto-fit + minmax — responsif tanpa media query untuk cards
1

Navbar — Flexbox

Logo di kiri, navigation links di kanan. Classic Flexbox pattern.

CSS:

.navbar {
    display: flex;
    justify-content: space-between;
    align-items: center;
    padding: 16px 40px;
    background: rgba(15, 23, 42, 0.95);
    position: sticky;
    top: 0;
    z-index: 100;
}

.nav-links {
    display: flex;
    gap: 32px;
    list-style: none;
}

/* Flexbox untuk navbar:
   → 1 dimensi (horizontal)
   → space-between mendistribusikan logo & links
   → gap mengatur jarak antar link */
2

Hero Section — Flexbox Column Center

Konten ditengahkan sempurna secara vertikal dan horizontal.

CSS:

.hero {
    display: flex;
    flex-direction: column;
    align-items: center;
    justify-content: center;
    min-height: 80vh;
    text-align: center;
    padding: 40px;
}

.hero-buttons {
    display: flex;    /* Tombol-tombol bersebelahan */
    gap: 16px;
    margin-top: 32px;
}

/* Flexbox column + center:
   → Pattern paling umum untuk hero section
   → min-height: 80vh memastikan hero cukup tinggi
   → Semua konten otomatis di tengah */
3

About Section — Grid 2 Kolom

Foto di kiri, bio di kanan. Grid cocok karena ini layout 2 dimensi.

CSS:

.about-grid {
    display: grid;
    grid-template-columns: 1fr 1.5fr;
    gap: 40px;
    align-items: center;
}

/* Kenapa Grid dan bukan Flexbox?
   → Kita mengontrol proporsi kolom (1fr vs 1.5fr)
   → align-items: center membuat foto & teks sejajar tengah
   → Grid memberikan kontrol presisi untuk layout 2 kolom */
4

Skills — Grid Auto-Fit + Flexbox Cards

Kartu skills responsif. Grid mengatur tata letak, Flexbox mengatur isi kartu.

CSS:

/* GRID — layout kartu responsif */
.skills-grid {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
    gap: 20px;
}

/* FLEXBOX — isi dalam kartu */
.skill-card {
    display: flex;
    flex-direction: column;
    align-items: center;
    text-align: center;
    padding: 30px 20px;
}

/* Combo pattern:
   Grid (luar) → berapa kolom, responsif otomatis
   Flexbox (dalam) → isi kartu tersusun vertikal */
5

Projects — Grid Gallery + Flexbox Cards

Sama seperti skills — Grid untuk gallery, Flexbox untuk card content.

CSS:

/* GRID — gallery layout */
.projects-grid {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
    gap: 24px;
}

/* FLEXBOX — card isi */
.project-card {
    display: flex;
    flex-direction: column;
}

.project-info {
    display: flex;
    flex-direction: column;
    padding: 20px;
    flex: 1;    /* mengisi sisa ruang */
}

.project-tags {
    display: flex;         /* tags bersebelahan */
    flex-wrap: wrap;       /* wrap ke baris baru jika penuh */
    gap: 8px;
    margin-top: auto;      /* dorong ke bawah */
}
6

Contact & Footer

Contact form 2 kolom dengan Grid. Footer columns juga Grid.

CSS:

/* Contact — Grid 2 kolom */
.contact-grid {
    display: grid;
    grid-template-columns: 1fr 1fr;
    gap: 20px;
}

.message-field {
    grid-column: 1 / -1;  /* textarea full width */
}

/* Footer — Grid untuk kolom */
.footer-grid {
    display: grid;
    grid-template-columns: 2fr 1fr 1fr 1fr;
    gap: 30px;
}

/* Flexbox dalam footer columns */
.footer-col {
    display: flex;
    flex-direction: column;
    gap: 8px;
}

Peta Grid vs Flexbox di Portfolio

Breakdown lengkap teknik yang digunakan di setiap section.

Peta:

PORTFOLIO
│
├── NAVBAR ──────── Flexbox (row, space-between)
│    → Logo kiri | Links kanan
│
├── HERO ────────── Flexbox (column, center)
│    → Semua konten di tengah + tombol-tombol
│
├── ABOUT ───────── Grid (1fr 1.5fr)
│    → 2 kolom: foto kiri, teks kanan
│    └── Stats ── Flexbox (row) → 3 angka sejajar
│
├── SKILLS ──────── Grid (auto-fit, minmax 200px)
│    → Responsif otomatis 2-3-4 kolom
│    └── Card ── Flexbox (column, center)
│
├── PROJECTS ────── Grid (auto-fit, minmax 300px)
│    → Gallery responsif
│    └── Card ── Flexbox (column)
│        └── Tags ── Flexbox (row, wrap)
│
├── CONTACT ─────── Grid (2 kolom form)
│    → Nama | Email (2 kolom)
│    → Subject | Pesan (full width via span)
│
└── FOOTER ──────── Grid (2fr 1fr 1fr 1fr)
     → Brand besar | 3 kolom links
     └── Cols ── Flexbox (column) → links vertikal

🎯 Tips Deploy ke Neocities

  • Neocities menghosting file statis — HTML + CSS langsung bisa di-upload
  • Buat file index.html + style.css lalu upload ke neocities.org
  • Ganti konten placeholder dengan info kamu sendiri
  • Website kamu akan live di username.neocities.org
