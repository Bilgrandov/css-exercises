📖 Dashboard Layout — Praktek Nyata

Sekarang kita akan menggabungkan semua yang sudah dipelajari untuk membangun dashboard layout yang sering ditemui di aplikasi web nyata:

Komponen Dashboard

  • Header — bagian atas, navigasi dan logo
  • Sidebar — menu navigasi vertikal di kiri
  • Main Content — area konten utama di tengah
  • Stats Cards — kartu statistik di dalam main content
  • Footer — informasi bawah

Teknik yang Digunakan

  • grid-template-areas — untuk layout utama (header, sidebar, main, footer)
  • repeat(auto-fit, minmax()) — untuk stats cards yang responsif
  • grid-column: span — untuk widget yang lebih besar

📝 Penjelasan Kode

Layout Utama (grid-template-areas):

.dashboard {
    display: grid;
    grid-template-columns: 220px 1fr;
    grid-template-rows: 60px 1fr 40px;
    grid-template-areas:
        "header  header"
        "sidebar main"
        "footer  footer";
    height: 100vh;
}

.dash-header  { grid-area: header; }
.dash-sidebar { grid-area: sidebar; }
.dash-main    { grid-area: main; }
.dash-footer  { grid-area: footer; }

Stats Cards (auto-fit responsif):

.stats-grid {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
    gap: 16px;
}

Charts Grid (span untuk widget lebar):

.charts-grid {
    display: grid;
    grid-template-columns: repeat(2, 1fr);
    gap: 16px;
}

.chart-card.wide {
    grid-column: span 2;  /* menempati 2 kolom */
}
