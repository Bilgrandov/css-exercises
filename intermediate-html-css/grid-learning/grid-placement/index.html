📍 Grid Placement

Menguasai grid-column, grid-row, dan span

📖 Grid Lines — Garis Tak Terlihat

Setiap grid punya garis-garis (lines) yang bernomor. Kolom dimulai dari garis 1 di kiri. Baris dimulai dari garis 1 di atas. Kita bisa menempatkan item di posisi manapun menggunakan nomor garis ini!

Sistem Penomoran Grid Lines

  Kolom:  1    2    3    4
          |    |    |    |
Baris 1— [ A ][ B ][ C ]
Baris 2— [ D ][ E ][ F ]
Baris 3— [ G ][ H ][ I ]
          |    |    |    |
         (garis 1-4 untuk 3 kolom)

Grid 3×3 punya 4 garis kolom (1-4) dan 4 garis baris (1-4).

Property Penempatan

  • grid-column-start / grid-column-end — posisi awal & akhir kolom
  • grid-row-start / grid-row-end — posisi awal & akhir baris
  • grid-column — shorthand: start / end
  • grid-row — shorthand: start / end
  • span — merentang beberapa kolom/baris

🎯 Demo 1: grid-column — Menempatkan Item di Kolom Tertentu

Item A direntangkan dari kolom 1 sampai kolom 3 (menempati 2 kolom).

A
column: 1 / 3
B
C
D
E

CSS:

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 10px;
}

/* Item A menempati kolom 1 sampai garis 3 */
.item-wide {
    grid-column: 1 / 3; /* dari garis 1 ke garis 3 = 2 kolom */
}

✅ Penting: grid-column: 1 / 3 artinya "mulai di garis 1, berakhir di garis 3". Ini bukan kolom 1 sampai kolom 3, tapi garis 1 sampai garis 3 = 2 kolom.

🎯 Demo 2: grid-row — Menempatkan Item di Baris Tertentu

Sidebar merentang dari baris 1 sampai baris 3 (2 baris).

Sidebar
row: 1 / 3
Main
Aside
Footer 1
Footer 2

CSS:

.sidebar {
    grid-row: 1 / 3; /* merentang 2 baris */
}

🎯 Demo 3: Kata Kunci span

Daripada menghitung nomor garis, gunakan span untuk bilang "rentangkan sekian kolom/baris".

Header
grid-column: span 4
Sidebar
grid-row: span 2
Content 1
Content 2
Content 3
Content 4
Content 5
Footer
grid-column: span 3

CSS:

.container {
    display: grid;
    grid-template-columns: repeat(4, 1fr);
    gap: 10px;
}

.header { grid-column: span 4; }    /* merentang 4 kolom */
.sidebar { grid-row: span 2; }       /* merentang 2 baris */
.footer { grid-column: span 3; }     /* merentang 3 kolom */

✅ span vs nomor garis: grid-column: span 3 = "rentangkan 3 kolom dari posisi saat ini." Lebih mudah dibaca daripada menghitung nomor garis!

🎯 Demo 4: Penempatan Spesifik dengan grid-column + grid-row

Kita bisa menempatkan item di posisi manapun — bahkan melompati sel!

A
col:1/2, row:1/2
B
col:3/4, row:1/3
C
col:1/3, row:3/4
D
col:2/3, row:2/3

CSS:

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    grid-template-rows: repeat(3, 100px);
    gap: 10px;
}

.pos-a { grid-column: 1 / 2; grid-row: 1 / 2; }
.pos-b { grid-column: 3 / 4; grid-row: 1 / 3; }  /* 2 baris tinggi */
.pos-c { grid-column: 1 / 3; grid-row: 3 / 4; }  /* 2 kolom lebar */
.pos-d { grid-column: 2 / 3; grid-row: 2 / 3; }

✅ Tips: Perhatikan bahwa item B menempati 2 baris (row 1-3), dan item C menempati 2 kolom (col 1-3). Sel kosong dibiarkan saja — grid tidak memaksamu mengisi semua sel!

📝 Ringkasan

Property Fungsi Contoh
grid-column Posisi kolom (start / end) 1 / 3 atau span 2
grid-row Posisi baris (start / end) 1 / 3 atau span 2
span Merentang N kolom/baris grid-column: span 3
grid-column-start Garis mulai kolom grid-column-start: 2
grid-row-end Garis akhir baris grid-row-end: 4
