📐 Grid Basics

Pengenalan display: grid, kolom, baris, dan gap

📖 Apa itu CSS Grid?

CSS Grid adalah sistem layout dua dimensi — artinya kamu bisa mengatur elemen secara horizontal (kolom) DAN vertikal (baris) sekaligus. Berbeda dengan Flexbox yang hanya satu dimensi.

Konsep Dasar

  • display: grid — Mengaktifkan grid pada container
  • grid-template-columns — Menentukan jumlah & lebar kolom
  • grid-template-rows — Menentukan jumlah & tinggi baris
  • gap — Jarak antar item grid (bisa juga row-gap dan column-gap)

🎯 Analogi

Bayangkan Grid seperti tabel Excel — kamu tentukan berapa kolom dan baris, lalu taruh konten di sel-sel yang kamu mau. Tapi jauh lebih fleksibel dari tabel HTML!

CSS:

.container {
    display: grid;
    grid-template-columns: 200px 200px 200px;
    gap: 10px;
}

✅ Penjelasan: Kita punya 6 item. Karena kita definisikan 3 kolom, item otomatis akan membuat 2 baris. Grid secara otomatis membuat baris baru ketika kolom sudah penuh!

🎯 Demo 2: Mengatur Baris dengan grid-template-rows

CSS:

.container {
    display: grid;
    grid-template-columns: 200px 200px 200px;
    grid-template-rows: 100px 150px;
    gap: 10px;
}

✅ Penjelasan: Baris pertama tingginya 100px, baris kedua 150px. Perhatikan perbedaan tinggi antara baris atas dan bawah!

CSS:

/* Gap sama rata */
.grid-1 { gap: 10px; }

/* Gap beda untuk baris dan kolom */
.grid-2 {
    row-gap: 30px;
    column-gap: 5px;
}

/* Shorthand: gap: row column */
.grid-3 { gap: 30px 5px; }

🎯 Demo 4: Campuran Ukuran Kolom

Setiap kolom bisa punya lebar yang berbeda!

CSS:

.container {
    display: grid;
    grid-template-columns: 100px 300px 150px;
    gap: 10px;
}

✅ Penjelasan: Ini menunjukkan bahwa setiap kolom bisa punya lebar yang berbeda. Sangat berguna untuk layout seperti sidebar + konten utama!

📝 Ringkasan

Property Fungsi Contoh
display: grid Aktifkan grid display: grid
grid-template-columns Atur jumlah & lebar kolom 200px 200px 200px
grid-template-rows Atur jumlah & tinggi baris 100px 150px
gap Jarak antar item 10px atau 20px 10px
