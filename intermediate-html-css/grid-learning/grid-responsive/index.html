📱 Grid Responsive

Layout responsif dengan auto-fill, auto-fit, dan minmax()

📖 Responsif Tanpa Media Queries?!

CSS Grid punya kemampuan luar biasa — membuat layout yang otomatis menyesuaikan jumlah kolom berdasarkan lebar layar, TANPA menulis satu pun media query!

Resep Ajaibnya

grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));

Artinya: "Buat sebanyak mungkin kolom, masing-masing minimal 250px. Jika ada ruang sisa, bagikan merata."

auto-fill vs auto-fit

  • auto-fill — Buat kolom sebanyak mungkin, termasuk kolom kosong (track ada tapi tidak terlihat)
  • auto-fit — Sama, tapi kolom kosong akan di-collapse (item yang ada melar mengisi ruang)

CSS:

.container {
    display: grid;
    grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
    gap: 16px;
}

/* auto-fill: buat kolom sebanyak mungkin
   minmax(200px, 1fr): minimal 200px, max 1fr
   Hasilnya: responsif otomatis! */

✅ Bagaimana ini bekerja? Browser menghitung: "Berapa kolom 200px yang muat?" Jika layar 800px → 4 kolom. Jika 600px → 3 kolom. Jika 400px → 2 kolom. Sisa ruang dibagi rata berkat 1fr.

Perbedaan terlihat ketika item sedikit. auto-fit membuat item melar mengisi ruang.

CSS:

/* auto-fill: kolom kosong tetap ada (tidak terlihat) */
.auto-fill {
    grid-template-columns: repeat(auto-fill, minmax(150px, 1fr));
}

/* auto-fit: kolom kosong di-collapse, item melar */
.auto-fit {
    grid-template-columns: repeat(auto-fit, minmax(150px, 1fr));
}

/* Perbedaan terlihat jelas ketika item < kolom yang tersedia */

✅ Kapan pakai mana? Gunakan auto-fit jika kamu mau item selalu mengisi seluruh lebar. Gunakan auto-fill jika kamu mau menjaga ukuran konsisten.
