📏 Grid Units

Menguasai fr, repeat(), minmax(), dan pencampuran unit

📖 Kenapa Perlu Unit Khusus Grid?

Menggunakan px saja untuk kolom membuat layout kaku. CSS Grid punya unit dan fungsi khusus yang membuat layout fleksibel dan responsif.

Unit & Fungsi Grid

  • fr — fraction, membagi ruang sisa secara proporsional
  • repeat(n, size) — mengulang pola kolom/baris sebanyak n kali
  • minmax(min, max) — ukuran minimal dan maksimal
  • auto — menyesuaikan dengan konten

🎯 Analogi fr

Bayangkan kamu punya pizza sisa setelah dipotong bagian tetap. 1fr = satu bagian dari pizza sisa. 2fr = dua bagian. Jadi 1fr 2fr berarti kolom kedua 2x lebih lebar dari kolom pertama!

CSS:

/* Sama rata — masing-masing 1/3 dari ruang */
.equal { grid-template-columns: 1fr 1fr 1fr; }

/* Tengah 2x lebih lebar — 1/4, 2/4, 1/4 */
.varied { grid-template-columns: 1fr 2fr 1fr; }

/* Sidebar + konten — 1/4 dan 3/4 */
.sidebar { grid-template-columns: 1fr 3fr; }

✅ Cara kerja fr: Pertama Grid menghitung total fr (misal 1+2+1=4). Lalu bagi ruang tersedia: kolom 2fr dapat 2/4 = 50% dari ruang. Coba resize browser — kolom akan ikut berubah!

CSS:

/* 4 kolom sama rata */
.grid-4 { grid-template-columns: repeat(4, 1fr); }

/* Pola berulang: 1fr 2fr 1fr 2fr 1fr 2fr */
.grid-pattern { grid-template-columns: repeat(3, 1fr 2fr); }

✅ Tips: repeat() sangat berguna ketika kamu punya banyak kolom dengan ukuran sama. Kamu juga bisa mengulang pola — repeat(3, 1fr 2fr) = 6 kolom!

🎯 Demo 3: Fungsi minmax()

Mengatur ukuran minimum dan maksimum sebuah kolom. Sangat penting untuk layout responsif!

grid-template-columns: minmax(150px, 1fr) minmax(250px, 2fr) minmax(150px, 1fr)

CSS:

.container {
    display: grid;
    grid-template-columns:
        minmax(150px, 1fr)
        minmax(250px, 2fr)
        minmax(150px, 1fr);
    gap: 10px;
}

✅ Cara kerja: Kolom tidak akan pernah lebih kecil dari nilai minimum (150px/250px), tapi akan melebar mengikuti fr ketika ada ruang. Coba resize browser!

CSS:

/* Fixed + flexible + auto */
.mix-1 {
    grid-template-columns: 250px 1fr auto;
}

/* Fixed + repeat + minmax */
.mix-2 {
    grid-template-columns: 200px repeat(2, 1fr) minmax(100px, 200px);
}

✅ Kapan pakai apa?

  • px — untuk bagian yang harus ukuran tetap (sidebar, icon column)
  • fr — untuk bagian yang harus fleksibel (konten utama)
  • auto — untuk bagian yang menyesuaikan kontennya
  • minmax() — untuk bagian yang butuh batas min/max
