🖼️ Grid Card Gallery

Membangun gallery kartu responsif dengan CSS Grid

📖 Gallery dengan Grid — Teknik Populer

Gallery kartu adalah pola yang paling sering ditemui di web: halaman produk, portfolio, blog posts, dan lainnya. Grid membuatnya sangat mudah!

Teknik yang Digunakan

  • repeat(auto-fit, minmax()) — untuk responsif otomatis
  • grid-row: span 2 — untuk kartu "featured" yang lebih tinggi
  • grid-column: span 2 — untuk kartu yang lebih lebar
  • Kombinasi auto-rows — untuk baris otomatis yang konsisten

CSS:

.gallery {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
    grid-auto-rows: auto;
    gap: 20px;
}

/* Kartu featured: lebar 2 kolom */
.featured-wide { grid-column: span 2; }

/* Kartu featured: tinggi 2 baris */
.featured-tall { grid-row: span 2; }

CSS:

.masonry {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    grid-auto-rows: 80px;  /* baris kecil sebagai unit */
    gap: 12px;
}

/* Setiap card span baris berbeda untuk efek masonry */
.masonry-1 { grid-row: span 3; }  /* 240px */
.masonry-2 { grid-row: span 2; }  /* 160px */
.masonry-3 { grid-row: span 4; }  /* 320px */
.masonry-4 { grid-row: span 2; }  /* 160px */
.masonry-5 { grid-row: span 3; }  /* 240px */
.masonry-6 { grid-row: span 2; }  /* 160px */

✅ Tips: Ini bukan masonry sempurna (untuk itu butuh JavaScript), tapi dengan grid-auto-rows kecil + span bervariasi, kita bisa mendekati efek masonry hanya dengan CSS!
