⚖️ Grid Alignment

Menguasai justify, align, dan place di CSS Grid

📖 Dua Sumbu di Grid

Grid bekerja dalam dua sumbu: horizontal (inline/row axis) dan vertikal (block/column axis). Property alignment di Grid membiarkan kamu mengontrol posisi item di kedua sumbu ini.

Peta Property Alignment

Horizontal (Justify) Vertikal (Align) Keduanya (Place)
Semua item (di container) justify-items align-items place-items
Satu item (di item) justify-self align-self place-self
Seluruh grid (di container) justify-content align-content place-content

🎯 Ingat Mudah

justify = horizontal →, align = vertikal ↓, place = shorthand keduanya (align dulu, justify kemudian).

CSS:

/* Posisi item di kiri sel */
.start   { justify-items: start; }

/* Posisi item di tengah sel */
.center  { justify-items: center; }

/* Posisi item di kanan sel */
.end     { justify-items: end; }

/* Tengah sempurna (vertikal + horizontal) */
.perfect { place-items: center center; }

/* Nilai: start | end | center | stretch (default) */

✅ Default: stretch — item mengisi seluruh sel. Ketika kamu ubah ke start/center/end, item menyusut sesuai kontennya.

CSS:

/* Grid menggunakan kolom 100px (lebih kecil dari container) */
.container {
    display: grid;
    grid-template-columns: repeat(2, 100px);
    grid-template-rows: repeat(2, 80px);
}

/* Posisikan seluruh grid di tengah container */
.center-grid  { justify-content: center; }

/* Ruang merata di antara kolom */
.space-between { justify-content: space-between; }

/* Ruang merata di sekitar semua kolom */
.space-evenly  { justify-content: space-evenly; }

/* Nilai: start | end | center | stretch |
   space-between | space-around | space-evenly */

✅ Kapan ini berguna? Ketika kolom/baris grid punya ukuran tetap (px) dan tidak mengisi seluruh container. Mirip dengan Flexbox justify-content!

📝 Ringkasan Cepat

Cheat Sheet

  • justify-items / align-items → posisi SEMUA item di sel mereka
  • justify-self / align-self → posisi SATU item di selnya
  • justify-content / align-content → posisi SELURUH GRID di container
  • place-* → shorthand: align justify
