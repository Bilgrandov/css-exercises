🏗️ Dashboard From Scratch

Membangun admin dashboard selangkah demi selangkah dengan Grid + Flexbox

📖 Apa yang Akan Kita Bangun?

Kita akan membangun sebuah admin dashboard lengkap dari nol. Setiap langkah dijelaskan alasan dan tekniknya. Di akhir, kamu akan punya dashboard profesional!

Teknologi: Grid untuk layout utama + kartu stats. Flexbox untuk header, sidebar items, dan konten dalam kartu.

1

Struktur HTML Dasar

Pertama, kita buat kerangka HTML — semua elemen utama dashboard.

HTML:

<div class="dashboard">
    <header class="header">...</header>
    <aside class="sidebar">...</aside>
    <main class="main-content">...</main>
    <footer class="footer">...</footer>
</div>

🤔 Kenapa HTML semantik?

<header>, <aside>, <main>, <footer> — menggunakan tag semantik bukan hanya <div> membuat kode lebih mudah dibaca dan bagus untuk accessibility.

2

Grid Layout Utama

Ini "tulang punggung" layout kita — menggunakan grid-template-areas.

CSS — Layout utama:

.dashboard {
    display: grid;
    grid-template-columns: 240px 1fr;
    grid-template-rows: 64px 1fr 48px;
    grid-template-areas:
        "header  header"
        "sidebar main"
        "sidebar footer";
    height: 100vh;
}

/* Kenapa grid-template-areas?
   → Kita bisa "menggambar" layout secara visual
   → Mudah diubah tanpa hitung nomor garis
   → Sidebar merentang 2 baris (main + footer) */

.header       { grid-area: header; }
.sidebar      { grid-area: sidebar; }
.main-content { grid-area: main; }
.footer       { grid-area: footer; }

3

Header — Flexbox untuk Navbar

Header punya 3 bagian: logo (kiri), search (tengah), profile (kanan). Flexbox sempurna untuk ini!

CSS — Header dengan Flexbox:

.header {
    display: flex;                /* Flexbox! */
    align-items: center;          /* vertikal tengah */
    justify-content: space-between; /* logo kiri, profile kanan */
    padding: 0 24px;
    background: #1e293b;
}

/* Kenapa Flexbox dan bukan Grid?
   → Header adalah satu baris (1 dimensi)
   → Item harus distributed secara fleksibel
   → space-between perfect untuk navbar pattern */

.search-box {
    display: flex;     /* Flexbox lagi! Untuk icon + input */
    align-items: center;
    gap: 8px;
}

4

Sidebar — Flexbox Column untuk Menu

Sidebar berisi menu vertikal. Flexbox column mengatur menu items + mendorong logout ke bawah.

CSS — Sidebar dengan Flexbox:

.sidebar {
    display: flex;
    flex-direction: column;   /* menu vertikal */
    background: #0f172a;
    padding: 16px 0;
    overflow-y: auto;
}

.sidebar-menu {
    display: flex;
    flex-direction: column;
    gap: 4px;
    flex: 1;    /* mengisi ruang tersedia */
}

.sidebar-bottom {
    margin-top: auto;  /* ⭐ Trik Flexbox: dorong ke bawah! */
    padding: 16px;
}

/* Teknik margin-top: auto di Flexbox column
   sangat populer untuk menaruh item terakhir
   di bagian bawah container. */

Stats Cards — Grid Auto-Fit

Kartu statistik responsif. Grid auto-fit mengatur jumlah kolom otomatis, Flexbox mengatur isi kartu.

CSS — Stats Grid:

/* GRID untuk layout kartu */
.stats-row {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
    gap: 20px;
    margin-bottom: 24px;
}

/* FLEXBOX untuk isi kartu */
.stat-card {
    display: flex;
    align-items: center;
    gap: 16px;
    padding: 20px;
    background: #1e293b;
    border-radius: 12px;
}

/* Kenapa Grid + Flexbox?
   Grid → mengatur POSISI kartu (berapa kolom, responsif)
   Flexbox → mengatur ISI kartu (icon + teks sejajar) */

Content Area — Grid 2 Kolom + span

Area konten utama pakai Grid 2 kolom. Chart besar pakai span 2.

CSS — Content Grid:

.content-grid {
    display: grid;
    grid-template-columns: 2fr 1fr;
    gap: 20px;
}

/* Chart besar menempati seluruh lebar */
.chart-large {
    grid-column: 1 / -1;  /* dari kiri sampai kanan */
    /* Atau bisa: grid-column: span 2; */
}

/* -1 artinya "garis terakhir"
   Teknik ini berguna jika jumlah kolom bisa berubah */

Peta Penggunaan Grid vs Flexbox

Setiap bagian dashboard menggunakan Grid atau Flexbox — masing-masing untuk alasan spesifik.

Peta:

DASHBOARD
├── .dashboard ──────── GRID (template-areas)
│    → Layout utama: header | sidebar | main | footer
│
├── .header ─────────── FLEXBOX (row)
│    → Logo | Search | Profile (space-between)
│
├── .sidebar ────────── FLEXBOX (column)
│    → Menu items vertikal + logout di bawah (margin-top: auto)
│
├── .main-content
│    ├── .stats-row ─── GRID (auto-fit)
│    │    → 4 stat cards responsif
│    │    └── .stat-card ── FLEXBOX (row)
│    │         → Icon + info sejajar
│    │
│    └── .content-grid ── GRID (2fr 1fr)
│         → Widget chart + orders + traffic
│         └── .widget ── FLEXBOX (column)
│              → Header + content
│
└── .footer ─────────── FLEXBOX (row)
     → Copyright | Links (space-between)

🎯 Aturan Emas

  • Grid ketika kamu perlu mengatur layout 2D (baris + kolom sekaligus)
  • Flexbox ketika kamu mengatur item dalam satu baris atau satu kolom
  • Grid auto-fit ketika kamu mau layout yang responsif otomatis
  • Flexbox margin-top: auto ketika kamu mau mendorong item ke bawah/kanan
