🗺️ Grid Areas

Membuat layout dengan grid-template-areas — cara paling mudah dibaca!

📖 Apa itu Grid Template Areas?

grid-template-areas memungkinkan kamu membuat layout dengan menulis "peta visual" langsung di CSS. Ini cara paling intuitif untuk membuat layout — kamu benar-benar menggambar layout-nya!

Cara Kerjanya

  1. Beri nama setiap area di container: grid-template-areas
  2. Assign setiap item ke area-nya: grid-area: nama
  3. Gunakan . (titik) untuk sel kosong

🎯 Analogi

Bayangkan kamu sedang menggambar denah rumah di kertas kotak-kotak. Kamu tulis "dapur" di beberapa kotak, "kamar" di beberapa kotak lain. Grid Areas bekerja persis seperti itu!

🎯 Demo 1: Layout Dasar dengan grid-template-areas

Layout klasik: Header di atas, Sidebar kiri, Konten utama kanan, Footer bawah.

Header
Sidebar
Main Content
Footer

CSS:

.container {
    display: grid;
    grid-template-columns: 200px 1fr;
    grid-template-rows: 60px 1fr 50px;
    grid-template-areas:
        "header  header"
        "sidebar main"
        "footer  footer";
    gap: 10px;
    height: 400px;
}

.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main    { grid-area: main; }
.footer  { grid-area: footer; }

✅ Lihat betapa mudahnya dibaca! Baris pertama: "header header" = header menempati 2 kolom. Baris kedua: "sidebar main" = sidebar kiri, main kanan. Baris ketiga: "footer footer" = footer penuh.

🎯 Demo 2: Sel Kosong dengan Titik (.)

Gunakan . untuk membuat sel yang kosong (tidak ditempati area apapun).

Nav
Main
Ads
Footer

CSS:

.container {
    display: grid;
    grid-template-columns: 1fr 3fr 1fr;
    grid-template-rows: 60px 1fr 50px;
    grid-template-areas:
        "nav   nav   nav"
        ".     main  ads"
        "footer footer footer";
    gap: 10px;
}

/* Perhatikan titik (.) di baris kedua kolom pertama!
   Itu akan menjadi sel kosong. */

✅ Penjelasan: Di baris kedua, kolom pertama punya . — artinya sel itu tidak ditempati siapapun. Sangat berguna untuk layout yang tidak simetris!

🎯 Demo 3: Layout Majalah

Grid Areas sangat cocok untuk layout yang kompleks tapi tetap mudah dibaca.

Judul Artikel
Gambar Utama
Cerita 1
Cerita 2
Cerita 3
Iklan

CSS:

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    grid-template-rows: auto 200px 150px;
    grid-template-areas:
        "title    title    title"
        "featured featured ad"
        "story1   story2   story3";
    gap: 10px;
}

✅ Kelebihan grid-template-areas: Mudah diubah layout-nya! Mau pindahkan iklan ke kiri? Tinggal edit teks areas-nya — tidak perlu hitung ulang nomor garis.

📝 Ringkasan

Property Dipakai Di Fungsi
grid-template-areas Container Menggambar "peta" layout
grid-area Item Me-assign item ke area
. (titik) Di dalam areas Sel kosong

⚠️ Aturan Penting

  • Setiap area harus berbentuk persegi panjang (tidak boleh L-shape)
  • Nama area tidak boleh ada spasi — gunakan camelCase atau dash
  • Jumlah nama per baris harus sama dengan jumlah kolom
