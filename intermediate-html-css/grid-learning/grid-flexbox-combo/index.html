🤝 Grid + Flexbox Combo

Menggabungkan Grid untuk layout & Flexbox untuk komponen — combo terkuat di CSS!

📖 Kapan Pakai Grid vs Flexbox?

Ini pertanyaan yang paling sering ditanyakan! Jawabannya: pakai keduanya! Masing-masing punya kekuatan sendiri.

🆚 Grid vs Flexbox

CSS Grid Flexbox
Dimensi 2D (baris + kolom) 1D (baris ATAU kolom)
Cocok untuk Layout halaman, grid kartu Navbar, card content, alignment
Kontrol Container mengatur layout Item lebih fleksibel
Konten Layout-first (struktur dulu) Content-first (konten dulu)

🎯 Aturan Emas

Grid untuk "tata letak besar" (layout halaman, grid section) → Flexbox untuk "komponen kecil" (navbar items, card content, buttons). Gunakan Grid di level atas, Flexbox di level dalam!

🎯 Demo 1: Pattern Dasar — Grid di Luar, Flexbox di Dalam

Kartu ditata dengan Grid, konten dalam kartu ditata dengan Flexbox.

CSS:

/* GRID — mengatur tata letak kartu */
.card-grid {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
    gap: 20px;
}

/* FLEXBOX — mengatur isi dalam kartu */
.card {
    display: flex;
    flex-direction: column;   /* susun vertikal */
    align-items: center;       /* tengah horizontal */
    text-align: center;
    padding: 24px;
}

/* Tombol selalu di bawah berkat flex */
.card button {
    margin-top: auto;         /* dorong ke bawah! */
}

✅ Key insight: Grid mengatur POSISI kartu di halaman. Flexbox mengatur KONTEN di dalam setiap kartu. margin-top: auto di Flexbox mendorong tombol ke bawah — trik yang sangat berguna!

📝 Peta Grid + Flexbox di Halaman Ini

Peta Penggunaan:

HALAMAN WEB
│
├── NAV ─────────────── Flexbox (row) → logo | links | button
│
├── HERO ────────────── Flexbox (column) → text | buttons (row)
│
├── FEATURES SECTION
│   └── .features-grid ── Grid (auto-fit) → 4 cards
│       └── .feature-card ── Flexbox (column) → icon | title | text
│
├── TESTIMONIALS
│   └── .testimonials-grid ── Grid (3 columns) → 3 testimonials
│       └── .testimonial ── Flexbox (column) → quote | author-row
│           └── .author ── Flexbox (row) → avatar | name
│
└── FOOTER
    └── .footer-grid ── Grid (4 columns) → 4 footer sections
        └── .footer-col ── Flexbox (column) → title | links

✅ Pattern: Perhatikan polanya — Grid selalu digunakan di level "tata letak" (mengatur posisi section/cards), sedangkan Flexbox digunakan di level "komponen" (mengatur isi di dalam card, navbar, footer column). Ini adalah pattern yang digunakan oleh sebagian besar website modern!
